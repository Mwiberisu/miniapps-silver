# eXtensible Markup Language(XML)

## Special Characters

| Character |          Description          | Entity Name | Usage   |
| --------- | :---------------------------: | ----------: | ------- |
| “         | Quotation mark (double quote) |        quot | &quot\; |
| &         |           Ampersand           |         amp | &amp\;  |
| ‘         |   Apostrophe (single quote)   |        apos | &apos\; |
| <         |        Less than sign         |          lt | &lt\;   |
| >         |       Greater than sign       |          gt | &gt\;   |
